# Carte de fidélité Wallet

Cartes de fidélité à tampons pour **Apple Wallet** et **Google Wallet**, avec une appli web installable
(PWA) pour que les commerçants scannent les cartes de leurs clients.

Le projet est dans le dossier [`wallet-fidelite/`](./wallet-fidelite) : voir son
[`README.md`](./wallet-fidelite/README.md) pour l'installation et l'avancement, et son
[`CLAUDE.md`](./wallet-fidelite/CLAUDE.md) pour le cahier des charges.
